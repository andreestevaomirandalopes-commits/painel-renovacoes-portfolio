# Painel de Renovações

Sistema demonstrativo para gestão de clientes, renovações e processos internos.

## Sobre o projeto

O Painel de Renovações foi desenvolvido com o objetivo de centralizar informações, facilitar o acompanhamento de renovações e organizar processos operacionais em um único ambiente.

Este repositório apresenta uma versão demonstrativa do projeto, utilizando dados fictícios e sem expor informações sensíveis.

## Problema

Processos de acompanhamento de clientes e renovações podem ficar dispersos em planilhas, sistemas e controles manuais, dificultando a organização e aumentando o risco de perda de informações importantes.

## Solução

A proposta do sistema é concentrar essas informações em um painel único, oferecendo uma visão mais organizada dos clientes, status, renovações e processos internos.

## Funcionalidades

- Gestão de clientes
- Acompanhamento de renovações
- Controle de status
- Organização de processos internos
- Dashboard com informações resumidas
- Autenticação de usuários
- Integrações via API
- Integração com WhatsApp/Meta

## Tecnologias

- Next.js
- React
- TypeScript
- PostgreSQL
- Prisma ORM
- Auth.js
- APIs REST
